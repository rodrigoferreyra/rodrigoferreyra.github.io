# Rodrigo Ferreyra — Technical Writer Website

Minimal single-page GitHub Pages site.

## Before publishing

Replace these placeholders in `index.html`:

- `YOUR_EMAIL@example.com`
- `https://www.linkedin.com/in/YOUR-LINKEDIN/`
- `https://github.com/YOUR-GITHUB`

Then add the real client/product screenshots to the Unaric case study and replace the `Client / product image` placeholder.

The content is intentionally a V1 draft and can be refined later.

## GitHub Pages

Upload the three site files (`index.html`, `style.css`, `script.js`) to the repository root and enable GitHub Pages from the repository's Pages settings.
